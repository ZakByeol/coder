- 본래의 루트노드 Root, 루트노드가 될 노드 Parent가 주어짐 1. Parent의 부모 노드를 본래 Root의 부모노드(GP)로 초기화, GP의 자식노드를 Parent로 초기화 [GP와 Parent의 대소관계 확인 필요],[GP의 존재여부 확인 필요 - 포인터 값 확인] - GP 처리 2. Root의 부모 노드를 Parent으로 초기화, 오른쪽 자식 노드를 Parent의 왼쪽 서브트리(PLST)로 초기화, - 회전 그리고 해당 PLST의 부모노드를 Root노드로 초기화 - PLST의 처리 [이때, PLST의 NILL 여부를 판별하여 NILL에 부모노드가 생기지 않도록 방지] 3. Parent의 왼쪽 자식노드를 Root 노드로 초기화 - 여기서, Recoloring은 구현 안함 * 이중흑색노드가 부모노드의 왼쪽 자식인 경우, 오른쪽 자식이면 방향을 반대로만 해준다. 1. Basic logics "이중흑색노드 위치" 변수를 NULL로 선언, 삭제 노드(D)를 삭제하고 D의 부모노드(P)와 승격될 노드(C)를 양방향 연결해준다. (자식이 2개라면, D의 오른쪽 서브트리의 가장 왼쪽 노드 M을 찾아 M의 값을 D에 복사한 뒤, D = M으로 바꿔서 아래 로직을 그대로 적용한다.) (자식이 1개라면 D의 자식을 D자리로 올라오면서 P와 양방향 연결해준다.) D가 BLACK이라면 올라온 C노드가 BLACK이라면 "이중흑색노드 위치" 변수를 해당 C노드로 초기화시키고 아래의 2. Handle 4 Case으로 이행한다. 올라온 C노드가 RED이라면 BLACK으로 Recoloring한다. D가 RED이라면 끝난다. 2. Handle 4 Case ________________루프____________________(이중흑색노드 != NULL && 이중흑색노드 != 루트노드) ⓐ 이중 흑색 노드의 형제(S)가 RED인 경우 기본 로직을 이행 후, 해당 조건 충족시, S를 BLACK, P를 RED로 Recoloring한다. P를 기준으로 좌회전을하여 이 3가지의 과정을 통해 ⓑ-1, ⓑ-2, ⓑ-3 중 해당하는 케이스로 처리한다. ⓑ S가 BLACK인 경우 ⓑ-1 S의 양쪽 자식이 모두 검은색인 경우 이중흑색노드를 없애기 위해서, 해당 "이중흑색노드 위치" 변수를 P로 초기화시키고, S를 RED으로 Recoloring한다 (BH맞추기) 해당 P가 RED이면, BLACK으로 Recoloring을 한 후, "이중흑색노드 위치" 변수를 NULL로 초기화한다. (RED이면, BLACK으로 색을 칠해도 상관 없음 : 이중흑색노드도 BH에 이미 집계된 상태이기 때문) 해당 P가 BLACK이면, P를 이중흑색노드로 지정 후 조건에 맞춰 루프한다. ⓑ-2 S의 왼쪽 자식은 RED, 오른쪽 자식은 BLACK인 경우 기본 로직을 이행 후, 해당 조건 충족시, S를 RED로, S의 왼쪽자식(LC)를 BLACK으로 Recoloring한 후, S기준 우회전을 한다. (ⓐ와 마찬가지로 ⓑ-3으로 전환해서 해당 방식으로 처리하기 위함) ⓑ-3 S의 오른쪽 자식(RC)이 RED인 경우 곧 P가 뿌리인 서브트리에서 뿌리가 될 S에 P의 색으로 Recoloring 한다. (서브트리의 루트노드 색을 바꾸지 않게 하기 위함임) P와 RC를 BLACK으로 Recoloring한다. (P가 속한 전체 뿌리노드의 서브트리의 반대편의 서브트리의 Black Height 크기보다 P가 속한 서브트리가 +1 가 되기 위함임) P를 기준으로 좌회전 후, "이중흑색노드 위치" 변수를 NULL로 초기화한다.
