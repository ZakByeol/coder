- 본래의 루트노드 Root, 루트노드가 될 노드 Parent가 주어짐 1. Parent의 부모 노드를 본래 Root의 부모노드(GP)로 초기화, GP의 자식노드를 Parent로 초기화 [GP와 Parent의 대소관계 확인 필요],[GP의 존재여부 확인 필요 - 포인터 값 확인] - GP 처리 2. Root의 부모 노드를 Parent으로 초기화, 오른쪽 자식 노드를 Parent의 왼쪽 서브트리(PLST)로 초기화, - 회전 그리고 해당 PLST의 부모노드를 Root노드로 초기화 - PLST의 처리 [이때, PLST의 NILL 여부를 판별하여 NILL에 부모노드가 생기지 않도록 방지] 3. Parent의 왼쪽 자식노드를 Root 노드로 초기화 - 여기서, Recoloring은 구현 안함 새 노드를 빨간색으로 BST를 통해 삽입을 함. 부모노드가 빨간색이면, 규칙을 위반하기 때문에 이 경우에는 3가지의 경우로 나뉘어 대처방법을 달리 한다. - 삽입, 새노드 컬러링,NILL연결, 대처(3방안) ★ 대처방안 1 - 삽입노드의 삼촌노드가 빨간색 일때, 빨간색 노드를 Recoloring 한다는 것은 해당 노드의 서브트리의 BlackHegiht를 1증가한다는 것 외에 아무 문제가 없다는 뜻 임으로, 해당 노드와 형제 관계인 노드를 전부 검은색으로 Recoloring 한다. 굳이 삼촌을 고른 이유는, [같은 레벨인 부모 노드를 검은색으로 Recoloring 해야하기 때문이다.] 이후, 할아버지 노드를 빨간색으로 Recoloring하고, 할아버지 노드를 삽입노드로 삼아 부모노드가 검은색이거나, 이게 루트노드가 될때까지 계속 진행한다. 2- 삼촌이 검은색이며 새로 삽입한 노드가 부모 노드의 오른쪽 자식인 경우 P노드와 N노드를 좌회전하여 2번 케이스와 같은 배치 상태를 만들고 2번 케이스와 똑같이 대처한다. 이는 대소 상관관계가 유지되어 이렇게 진행한다. 현재노드를 본래 P로, P를 본래 N으로 초기화한다. 3 - 삼촌이 검은색이며, 새로 삽입한 노드가 부모 노드의 왼쪽 자식인 경우 전에 주어진 케이스의 경우, P의 색상을 검은색으로(빨간색 노드의 규칙 준수하기 위해), G의 색상을 빨간색으로(P의 Recoloring/회전으로 인한 G 아래의 불균형) Recoloring한다. 이후, 우회전한다. * 삭제노드가 부모노드의 왼쪽 자식인 경우, 오른쪽 자식이면 방향을 반대로만 해준다. 1.
